Help keep the timers right

This site runs on readings from players like you. One reading takes about 20 seconds and fixes a server's timer for everyone.

  1. Join a server and look at the in-game info: the server ID, the server uptime and Seraphiel's time left.
  2. Add a reading with those three things. Do it right away and leave the time blank, or note the exact time from time.is and enter it later.
  3. Saw Seraphiel spawn? Report it. That resets her timer on that server.

Add a reading

Anyone can add one. Copy the server ID and uptime from the game. Seraphiel's time left is the most useful part: it makes the timer exact. If you're typing this in right away, leave "Time you read it" blank. If you wrote it down earlier, enter the exact time you read it, in your own time zone. For an exact clock, use time.is.

Report a spawn

Saw Seraphiel appear? Pick the server and the uptime she spawned at, or leave it blank for "just now".

How it works

  • The server list updates itself. Every minute the site checks Everveil's public servers on Roblox for new servers, closed servers and player counts.
  • Seraphiel's timer. She first appears 1 hour after a server starts. Once she's defeated, the next one comes 1 hour later. Each fight adds about 5 to 10 seconds before the next timer starts, so spawns drift a little over time; the ± next to a time shows how sure the estimate is.
  • New servers are timed automatically. Servers that were already running need one reading from a player. Anyone can add one under "Add a reading", and Seraphiel's time left from the game makes the timer exact.
  • Time zones don't matter. Every time on this page is either a countdown or a server's uptime, so it's the same for everyone everywhere. The only clock time you ever type is "Time you read it", in your own local time, and the site converts it for you.
  • Use an exact clock. Your computer or phone clock can be off by a minute or more. When you note down a reading to enter later, check the time on time.is, or just leave the time blank and enter it right away.
  • White Death has a 25% chance to appear every 2 hours of server uptime. Servers show a note when one could be close.
  • Join a minute or two early. All times are estimates.
